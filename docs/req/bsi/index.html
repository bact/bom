Concepts (20)

IDLabelNotationTypeDefinition
component-creatorComponent creatorBOM-BSI-COMP-001RequirementEmail address (or URL if no email available) of the entity that created and maintains the component. (BSI TR-03183-2 uses 'creator' (the entity that authored the component) rather than 'supplier' (the entity that provides it). Distinct from NTIA's 'Supplier Name'.)
component-nameComponent nameBOM-BSI-COMP-002RequirementName assigned to the component by its creator; if no name is assigned, the actual filename MUST be used.
component-versionComponent versionBOM-BSI-COMP-003RequirementIdentifier used by the creator to specify changes relative to a previously created version; preferably Semantic Versioning or Calendar Versioning.
component-filenameFilename of the componentBOM-BSI-COMP-004RequirementThe actual filename of the component (i.e. not its file system path) as deployed.
component-dependenciesDependencies on other componentsBOM-BSI-COMP-005RequirementEnumeration of all components on which this component directly depends or which it contains, with an explicit completeness indication.
component-distribution-licenseDistribution licencesBOM-BSI-COMP-006RequirementThe licence(s) under which the component can be used by a licensee (i.e. the concluded/distribution licence expressed as an SPDX licence expression). (BSI TR-03183-2 distinguishes 'distribution licences' (concluded, what a downstream recipient may do) from 'original licences' (declared, what the upstream creator states). This concept covers the former.)
component-hash-deployableHash value of the deployable componentBOM-BSI-COMP-007RequirementSHA-512 cryptographic checksum of the deployed or deployable form of the component (as a file on a mass storage device). (BSI TR-03183-2 mandates SHA-512 specifically. The bridge concept bom:component-hash is algorithm-agnostic.)
component-executable-propertyExecutable propertyBOM-BSI-COMP-008RequirementWhether the component is executable; possible values: 'executable' / 'non-executable'.
component-archive-propertyArchive propertyBOM-BSI-COMP-009RequirementWhether the component is an archive; possible values: 'archive' / 'no archive'.
component-structured-propertyStructured propertyBOM-BSI-COMP-010RequirementWhether the component is a structured file whose internal metadata is still present; possible values: 'structured' / 'unstructured'.
component-source-uriSource code URIBOM-BSI-COMP-011ConditionalRequirementURI of the source code of the component (e.g. a versioned repository URL), required if it exists.
component-distribution-uriURI of the deployable form of the componentBOM-BSI-COMP-012ConditionalRequirementURI pointing directly to the deployable (e.g. downloadable) form of the component, required if it exists.
component-identifiersOther unique identifiersBOM-BSI-COMP-013ConditionalRequirementOther identifiers usable to identify the component or look it up in relevant databases (CPE, SWID, Package URL / PURL), required if they exist.
component-original-licenseOriginal licencesBOM-BSI-COMP-014ConditionalRequirementThe licence(s) assigned by the creator of the component (i.e. the declared/upstream licence), required if it exists. (Corresponds to the 'declared' licence perspective. Contrast with bsi:component-distribution-license (concluded). Both map to the general bridge concept bom:component-license.)
component-license-effectiveEffective licenceBOM-BSI-COMP-015PermissionThe licence under which the component is actually used by the licensee that is the creator of the current SBOM (optional).
component-hash-sourceHash value of the source code of the componentBOM-BSI-COMP-016PermissionCryptographic checksum of the component source code (algorithm not yet standardised in TR-03183-2; optional).
component-security-txtURL of the security.txtBOM-BSI-COMP-017PermissionURL of the component creator's security.txt file (RFC 9116) providing coordinated vulnerability disclosure contact information (optional).
doc-creatorCreator of the SBOMBOM-BSI-DOC-001RequirementEmail address (or URL if no email available) of the entity that created the document.
doc-timestampTimestampBOM-BSI-DOC-002RequirementDate and time of the SBOM data compilation, preferably in UTC.
doc-uriBOM-URIBOM-BSI-DOC-003ConditionalRequirementA URI uniquely identifying this document (required if it exists).
